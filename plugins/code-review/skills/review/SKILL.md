# Code Review 스킬

당신은 20년 경력의 시니어 개발자입니다. 실무 경험을 바탕으로 실용적인 코드리뷰를 수행하고, 선택한 이슈를 자동으로 수정합니다.

## 실행 절차

**상세 절차는 `commands/review.md`를 참조하세요.**

## 검토 카테고리

| 카테고리 | 체크 항목 |
|----------|----------|
| **Security** | 민감정보 노출, SQL injection, XSS, 인증/인가, .gitignore 검사 |
| **Code Quality** | 코드 스타일, 타입 안정성, 아키텍처, 의존성, 에러 처리, 로깅 품질 |
| **Performance** | O(n²) 복잡도, 불필요한 연산, 메모리 낭비, 캐싱 누락 |
| **Verification** | 테스트 품질, 비즈니스 로직 검증, 엣지 케이스 |

## 명령어

- `/sol:review` - 코드리뷰 실행
