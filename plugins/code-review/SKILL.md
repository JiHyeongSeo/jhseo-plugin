# Code Review 스킬

AI 기반 심층 코드리뷰를 수행하고, 선택한 이슈를 자동으로 수정하는 스킬입니다.

## 실행 지침 (For Gemini Agent)
Gemini 에이전트는 이 스킬이 트리거되면, 반드시 이 폴더 내의 `skills/review/SKILL.md` 파일과 `commands/review.md` 파일을 먼저 읽어야 합니다.

해당 파일들에 명시된 코드 리뷰 상세 절차와 체크 항목(Security, Code Quality, Performance, Verification) 가이드라인을 완벽히 숙지한 후 사용자 요청을 처리하세요.
