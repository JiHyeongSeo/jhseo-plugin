# Review/Auto-Review 스킬 통합 설계

## 개요

`/sol:review`와 `/sol:auto-review` 두 스킬을 하나의 `/sol:review`로 통합합니다.

## 통합 플로우

```
┌─────────────────────────────────────────────────────────┐
│  /sol:review 실행                                        │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│  1단계: 카테고리 선택                                     │
│  ○ All (전체 검토) - 4개 카테고리 모두 검토               │
│  ○ Custom (직접 선택) - 원하는 카테고리만 선택            │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│  2단계: 리뷰 진행 → 결과 출력                             │
│  - 이슈를 필수/권장/선택으로 분류하여 표시                 │
└─────────────────────────────────────────────────────────┘
                          │
                          ▼
┌─────────────────────────────────────────────────────────┐
│  3단계: 반영 여부 질문 (체크박스)                          │
│  ☑ 필수 (Critical) - N개                                │
│  ☑ 권장 (Major) - N개                                   │
│  ☐ 선택 (Minor) - N개                                   │
│  ☐ 반영 없이 종료                                        │
└─────────────────────────────────────────────────────────┘
                          │
            ┌─────────────┴─────────────┐
            ▼                           ▼
    [반영 없이 종료]              [이슈 선택됨]
            │                           │
            ▼                           ▼
        종료                 ┌─────────────────────────────┐
                            │  4단계: 선택한 이슈 자동 수정  │
                            └─────────────────────────────┘
                                        │
                                        ▼
                            ┌─────────────────────────────┐
                            │  5단계: 1회 재검토            │
                            │  - 새로운 이슈 발견 시 리포트 │
                            │  - "추가 수정 원하시면 다시   │
                            │    호출해주세요" 안내         │
                            └─────────────────────────────┘
                                        │
                                        ▼
                                      종료
```

## 상세 구현

### 3단계 반영 여부 질문 UI

```yaml
question: "반영할 이슈를 선택하세요"
header: "Fix"
multiSelect: true
options:
  - label: "🔴 필수 (Critical) - N개"
    description: "프로덕션 배포 전 반드시 수정"
  - label: "🟡 권장 (Major) - N개"
    description: "코드 품질 향상, 기술 부채 방지"
  - label: "🔵 선택 (Minor) - N개"
    description: "시간 여유 있을 때 개선"
  - label: "반영 없이 종료"
    description: "리뷰 결과만 확인하고 종료"
```

## 기존 대비 변경점

| 항목 | 기존 | 통합 후 |
|------|------|--------|
| 명령어 | `/sol:review`, `/sol:auto-review` | `/sol:review` |
| 수정 여부 | review는 수동, auto-review는 자동 | 사용자 선택 후 자동 |
| 반복 횟수 | auto-review는 최대 3회 | 1회 재검토 후 종료 |
| 이슈 선택 | auto-review는 Critical만 | 필수/권장/선택 모두 선택 가능 |
