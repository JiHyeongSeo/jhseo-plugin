슬롯 선택 프롬프트

Enter를 눌렀을 때 슬롯이 2개 이상이면 어떻게 물어볼까요?

A

터미널 텍스트 프롬프트

현재 삭제 확인창과 같은 방식. fzf 화면이 지워지고 아래처럼 표시됨.

어느 슬롯에 열까요?
1) 위 │ clean-chatbot — 로깅 개선 작업
2) 아래│ claude-plugins — session manager
N) 새 슬롯 추가

선택 (1/2/N): _

장점

  • 구현 단순
  • 기존 패턴과 일관성

단점

  • fzf 화면 깜빡임
  • Ctrl+C 버그 위험 (기존 이슈)
B

tmux display-popup

fzf 위에 떠 있는 팝업창. fzf 화면은 그대로 유지되면서 오버레이로 선택창 등장.

슬롯 선택
▶ 1) 위 │ clean-chatbot
   2) 아래│ claude-plugins
   N) 새 슬롯 추가
↑↓ 이동  Enter 선택  Esc 취소

장점

  • fzf 화면 유지
  • Esc로 취소 자연스러움
  • 화살키 이동 가능

단점

  • 구현 복잡도 높음
  • tmux 버전 의존성
C

키 바인딩으로 구분

프롬프트 없이 키로 직접 슬롯 지정. 슬롯이 몇 개든 항상 같은 방식.

fzf 헤더에 표시:
Enter = 슬롯1(위)에 열기
Ctrl+Enter = 슬롯2(아래)에 열기
Ctrl+S = 새 슬롯 추가

장점

  • 가장 빠름 (프롬프트 없음)
  • 구현 단순

단점

  • 슬롯 3개 이상이면 키 부족
  • 기억해야 함
