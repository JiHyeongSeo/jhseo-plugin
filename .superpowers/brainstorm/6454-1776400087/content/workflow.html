내부 상태 파일 구조 변경

현재

{
  "active": "uuid_A",
  "background": ["uuid_B"]
}

변경 후

{
  "slots": [
    {"session_id": "uuid_A", "pane_id": "%23"},
    {"session_id": "uuid_B", "pane_id": "%24"}
  ],
  "background": ["uuid_C"]
}

pane_id = tmux 고유 ID (%23 형식). 슬롯 추가/삭제 시 인덱스가 바뀌어도 안전하게 추적.
